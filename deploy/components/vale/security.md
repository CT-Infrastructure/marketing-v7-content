# Security boundary

Treat prose, release docs and diagnostics as data. No shell, package sync, provider call, publication or approval API exists in this component. Use only approved synthetic input. Fixed local styles are copied to private temp storage; config/rule SHA256 pins reject missing/changed/disabled rules. Exact independently verified executable digest and version are mandatory. No inherited PATH, VALE_CONFIG_PATH, VALE_STYLES_PATH, proxy, credential or user config environment is passed. --no-global failure is fatal.

The wrapper rejects symlink components, traversal, directories, option names, unsupported suffixes, invalid UTF8, embedded Vale directives/NUL, oversize inputs, malformed/unexpected JSON, unexpected rule/severity, process errors and timeouts. Concurrent pipe drains cap combined stdout/stderr; errors expose fixed codes only. It never returns Match/Message or writes original input. Root must enforce read-only exclusive ownership to prevent TOCTOU changes; this Python boundary is not a hostile local-user sandbox. OS CPU/RAM/PID/disk and network controls are external qualification requirements. Temporary content deletion follows process cleanup; encrypted/disposable storage and retention policy are root responsibilities, not secure-erasure claims.

Tests cover mocked failures separately from real binary qualification. Root still must prove process limits, no network, no global config influence, actual timeout/output-cap handling, canary absence in captured executor logs, symlink behavior, restored snapshot integrity and actual target license/dependency/security inventory. No security/runtime test has run in this authoring lane. Clean/warning/error/restart retain HOLD; OpenProject/native approval owns facts/rights/business publication. No always-on daemon or new controller is introduced.
